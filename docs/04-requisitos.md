# Requisitos funcionais e não funcionais — ConectaGlobal

## 1. Requisitos funcionais

| ID | Requisito | Prioridade |
|---|---|---|
| RF-01 | O sistema deve permitir ao estudante consultar oportunidades internacionais publicadas. | Alta |
| RF-02 | O sistema deve permitir filtrar oportunidades por país, área, duração, modalidade e prazo. | Alta |
| RF-03 | O sistema deve apresentar detalhes da oportunidade, incluindo requisitos, prazos, benefícios e documentos. | Alta |
| RF-04 | O sistema deve permitir ao estudante realizar autoavaliação inicial de elegibilidade conforme critérios cadastrados para a oportunidade. | Alta |
| RF-05 | O sistema deve disponibilizar recursos de preparação sobre idiomas, cultura e planejamento financeiro. | Média |
| RF-06 | O sistema deve permitir ao estudante registrar manifestação de interesse ou candidatura a uma oportunidade. | Alta |
| RF-07 | O sistema deve permitir ao estudante organizar e acompanhar documentos e pendências da candidatura. | Alta |
| RF-08 | O sistema deve apresentar ao estudante o status e o histórico de sua candidatura. | Alta |
| RF-09 | O sistema deve permitir à equipe do NEI cadastrar, editar, publicar, suspender e encerrar oportunidades e editais. | Alta |
| RF-10 | O sistema deve permitir à equipe do NEI cadastrar e manter instituições parceiras, convênios e bolsas. | Alta |
| RF-11 | O sistema deve permitir à equipe do NEI consultar e gerenciar candidaturas recebidas. | Alta |
| RF-12 | O sistema deve permitir à equipe do NEI registrar atualizações de status e observações de análise da candidatura. | Alta |
| RF-13 | O sistema deve emitir notificações sobre prazos, pendências e mudanças de status. | Média |
| RF-14 | O sistema deve permitir o registro e a consulta de relatos de experiência de mobilidade. | Média |
| RF-15 | O sistema deve permitir a participação em atividades de mentoria entre estudantes e ex-intercambistas. | Média |
| RF-16 | O sistema deve disponibilizar espaço Tandem para troca de idiomas entre participantes. | Média |
| RF-17 | O sistema deve permitir divulgar e consultar eventos, workshops, palestras e fórum de dúvidas. | Média |
| RF-18 | O sistema deve gerar relatórios gerenciais sobre candidaturas, perfis de interesse e destinos procurados. | Média |
| RF-19 | O sistema deve permitir ao administrador gerenciar usuários, perfis e permissões. | Alta |
| RF-20 | O sistema deve permitir ao estudante estrangeiro recebido consultar informações e recursos de integração. | Média |

## 2. Requisitos não funcionais

| ID | Requisito | Critério inicial |
|---|---|---|
| RNF-01 | Usabilidade | Interfaces consistentes, linguagem clara e fluxos compreensíveis. |
| RNF-02 | Acessibilidade | Considerar WCAG 2.2 nível AA como referência para interfaces. |
| RNF-03 | Responsividade | Disponibilizar experiência adequada em dispositivos móveis e desktops. |
| RNF-04 | Segurança | Restringir funções e dados conforme perfil e permissões. |
| RNF-05 | Privacidade | Tratar dados pessoais conforme princípios e obrigações da LGPD. |
| RNF-06 | Integridade | Validar campos obrigatórios, formatos e consistência dos dados cadastrados. |
| RNF-07 | Desempenho | Consultas comuns devem apresentar resposta em tempo adequado; metas numéricas serão definidas na P2. |
| RNF-08 | Disponibilidade | A solução deverá apresentar disponibilidade compatível com o uso previsto; meta será definida na P2. |
| RNF-09 | Auditabilidade | Registrar operações relevantes de gestão e alterações de status. |
| RNF-10 | Manutenibilidade | Organizar módulos e responsabilidades para permitir evolução do sistema. |
| RNF-11 | Compatibilidade | Suportar navegadores modernos e diferentes tamanhos de tela. |
| RNF-12 | Internacionalização | Preparar a solução para conteúdos em mais de um idioma quando necessário. |

## 3. Observações
- Os requisitos representam a proposta de escopo derivada da documentação-base e decisões de modelagem para a atividade acadêmica.
- A autoavaliação de elegibilidade é preliminar; não deve ser apresentada como decisão oficial de seleção.
- Integrações com sistemas institucionais não são presumidas.
- Regras específicas de editais devem ser configuráveis e detalhadas na P2.
