## 2. Decisões de projeto
| ID | Decisão | Justificativa |
|---|---|---|
| DP-01 | O produto é um Sistema de Gestão de Oportunidades Internacionais, não apenas um catálogo informativo. | Preserva a proposta original do ConectaGlobal. |
| DP-02 | O sistema contempla consulta, candidatura, acompanhamento e gestão das oportunidades. | Cobre o ciclo principal do domínio definido para o projeto. |
| DP-03 | Estudante, gestor, avaliador e administrador são os papéis conceituais do sistema. | Separa responsabilidades e permissões. |
| DP-04 | Critérios e documentos são configurados por oportunidade. | Evita generalizações indevidas. |
| DP-05 | Elegibilidade é informativa e não substitui avaliação humana. | Evita prometer aprovação automática. |
| DP-06 | Status e alterações relevantes são registrados em histórico. | Favorece transparência e rastreabilidade. |
| DP-07 | Integrações externas não são requisito obrigatório da versão acadêmica. | Mantém o escopo realizável e independente. |
| DP-08 | A DRI será consultada como referência visual durante a etapa de telas, sem ser integrada ao sistema. | Separa referência de interface de requisitos funcionais. |
| DP-09 | Fluxos e regras operacionais são decisões autorais, não processos institucionais validados. | Evita atribuir aprovação ou autoridade externa ao projeto. |

## 3. Limitações
Não foram realizadas entrevistas nem validações institucionais. As fontes públicas não comprovam processos internos, permissões, APIs ou integrações. Requisitos e fluxos apresentados são decisões acadêmicas da equipe e devem ser refinados na SRS.
