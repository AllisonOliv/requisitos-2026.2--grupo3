## Glossário do Projeto

| Termo/Sigla | Definição | Fonte/Observação |
|---|---|---|
| Mobilidade acadêmica internacional | Período de estudos ou atividade acadêmica realizado em instituição ou país diferente do de origem. | Documentação-base |
| Oportunidade internacional | Programa, edital, intercâmbio, bolsa ou modalidade de mobilidade disponível para candidatura. | Documentação-base |
| Edital | Documento que apresenta condições, critérios, prazos e etapas de uma seleção. | Domínio do projeto |
| Convênio | Acordo de cooperação entre instituições. | Domínio do projeto |
| Instituição parceira | Instituição estrangeira ou organização relacionada a uma oportunidade. | Domínio do projeto |
| Bolsa | Benefício financeiro associado a uma oportunidade, conforme condições próprias. | Documentação-base |
| Elegibilidade | Atendimento aos critérios exigidos para participação em determinada oportunidade. | Domínio do projeto |
| Autoavaliação | Verificação preliminar realizada pelo estudante com base nos critérios cadastrados. | Decisão de modelagem |
| Candidatura | Registro de interesse e informações do estudante para participar de uma oportunidade. | Domínio do projeto |
| Manifestação de interesse | Registro inicial do interesse do estudante em uma oportunidade. | Documento de propostas |
| Status da candidatura | Situação atual do processo, com histórico de alterações. | Decisão de modelagem |
| Portfólio digital | Conjunto organizado de informações e documentos do estudante relacionados à mobilidade. | Documentação-base |
| Incoming student | Estudante estrangeiro recebido pela instituição. | Documentação-base |
| Ex-intercambista | Estudante que já participou de mobilidade internacional. | Documentação-base |
| Tandem | Atividade de troca e prática de idiomas entre participantes. | Documentação-base |
| NEI | Núcleo de Estratégias Internacionais, ator organizacional identificado na documentação-base. | Documentação-base |
| Mentoria | Apoio oferecido por participante experiente a estudante interessado em mobilidade. | Documentação-base |
| Aproveitamento de créditos | Processo acadêmico de análise de estudos realizados durante a mobilidade. | Documentação-base |
| LAPIS | Referência metodológica utilizada para estruturar o processo e os artefatos de requisitos. | Repositório LAPIS |
| DRI | Diretoria/portal de Relações Internacionais consultado exclusivamente como referência visual futura das telas, sem papel de ator ou integração nesta modelagem. | Decisão expressa do projeto |
| RF | Requisito funcional. | Convenção de requisitos |
| RNF | Requisito não funcional. | Convenção de requisitos |
| CDU | Caso de uso. | Convenção LAPIS |
| NEC | Necessidade identificada. | Convenção LAPIS |
| F | Funcionalidade catalogada na Visão da Demanda. | Convenção LAPIS |
